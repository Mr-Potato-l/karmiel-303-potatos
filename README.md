## Welcome to PotetOS!
PotetOS is a small operating system intended for low-end devices, with the capability of a potato(hence the name).

It has a simple command-line interface, with a limited number of commands.

### Requirements:
You must have the following software to run the OS: 
1. QEMU Emulator
2. Make

### How to run:
1. Make sure you have the repo cloned.
2. Using a terminal, head to the directory which contains the make file.
3. Run the make file using `make`. You can add the `-j` parameter to allow it to use more threads to complete it faster.
4. After waiting for it to compile, the OS will start up!
